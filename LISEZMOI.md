# Ce projet exécute un pipeline ETL AssurRisk reliant Python et PostgreSQL pour charger et croiser des données de sinistres et de météo.
   Il produit également un journal d'exécution et des contrôles qualité, complétés par l'exploration analytique dans explorer.py.
   Pour lancer le pipeline : activez l'environnement virtuel (.venv\Scripts\activate) puis exécutez python pipeline.py.
   Saisissez votre mot de passe PostgreSQL lorsque le script le demande au lancement.
   Consultez les fichiers générés dans sorties/ pour vérifier le suivi et les contrôles.

# Ce projet exécute un pipeline ETL AssurRisk reliant Python et PostgreSQL pour charger et croiser des données de sinistres et de météo.
   Il produit également un journal d'exécution et des contrôles qualité, complétés par l'exploration analytique dans explorer.py.
   Pour lancer le pipeline : activer l'environnement virtuel (.venv\Scripts\activate) puis exécuter python pipeline.py.
   Saisir votre le mot de passe PostgreSQL lorsque le script le demande au lancement.
   Consulter les fichiers générés dans sorties/ pour vérifier le suivi et les contrôles.
